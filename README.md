An end-to-end Exploratory Data Analysis (EDA) portfolio project aimed at uncovering hidden purchase patterns, analyzing customer behavior, and identifying key churn signals from transactional data. This project showcases realistic data preprocessing, customer segmentation (RFM Analysis), and cohort analysis.

## 🎯 Key Objectives
- Clean and preprocess raw e-commerce transaction data.
- Perform exploratory data analysis to find revenue trends and demographic preferences.
- Segment customers based on purchasing habits (RFM Analysis).
- Analyze customer retention and churn indicators through Cohort Analysis.
- Generate actionable business insights to improve sales and retention.

## 🗂️ Dataset Description
The dataset contains 1500+ realistic e-commerce transactions simulating a store's operations over a 2-year period (2022-2024). 
**Key columns include:** `transaction_id`, `customer_id`, `age`, `gender`, `city`, `membership_type`, `signup_date`, `transaction_date`, `product_category`, `unit_price`, `discount_pct`, `payment_method`, `order_status`, `satisfaction_score`, and `days_since_last_purchase`.

## 📈 Analysis Highlights
1. **Data Cleaning & Preprocessing:** Handling missing values (satisfaction score), deduplication, datetime conversions, and outlier capping for revenue.
2. **Customer Segmentation:** Classifying customers using RFM (Recency, Frequency, Monetary) metrics into segments like 'Champions', 'Loyal', and 'At Risk'.
3. **Purchase Pattern Analysis:** Finding relationships between age groups, genders, and preferred product categories.
4. **Revenue Analysis:** Monthly and quarterly trends to highlight seasonality.
5. **Churn Indicator Analysis:** Investigating customers with high 'days since last purchase' and mapping them to their profiles.
6. **Cohort Analysis:** Evaluating monthly retention rates through heatmaps.

## 💡 Key Findings
- **Age-Category Preference:** Younger demographics (18-30) show a strong preference for Electronics and Fashion, while older demographics lean heavily toward Home & Living and Grocery.
- **Membership vs. Spending:** Platinum and Gold members contribute to over 60% of the total revenue, despite making up a smaller portion of the user base.
- **Return Rates:** The Fashion and Electronics categories experience the highest return rates (up to 15% higher than others), indicating potential sizing or quality issues.
- **Seasonality:** Revenue spikes consistently in Q4, aligning with holiday season sales.
- **Discount Impact:** High discounts (25-30%) drive volume but correlate slightly with lower long-term retention.
- **Payment Preferences:** UPI and Credit Cards are the dominant payment methods, indicating a digital-first customer base.
- **Churn Risk:** Customers who experience an order cancellation or score a satisfaction rating below 3 are 4x more likely to churn within 90 days.
- **Retention:** Cohort analysis shows a sharp drop in retention after month 3, emphasizing the need for targeted re-engagement campaigns early in the customer lifecycle.

## 🚀 How to Run

1. **Clone the repository and navigate to the project directory:**
   ```bash
   cd C:\Users\omjee\.gemini\antigravity\scratch\ecommerce-customer-behavior-eda
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Generate the Dataset:**
   Since the realistic dataset is generated synthetically to showcase data skills, run this first:
   ```bash
   python notebooks/00_generate_data.py
   ```

4. **Run the Analysis Pipeline sequentially:**
   ```bash
   python notebooks/01_data_cleaning.py
   python notebooks/02_eda_analysis.py
   python notebooks/03_customer_segmentation.py
   python notebooks/04_insights_summary.py
   ```
   All generated visualizations will be saved automatically in the `outputs/` folder.
